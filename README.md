# AI/ML Learning Journey

This repository tracks my daily progress in AI/ML learning.

## Structure

- `daily-log/` – Contains markdown files for each day's learning notes.
  Each file is named `learning-YYYY-MM-DD.md` and summarizes what was studied, lessons completed, quiz scores, and notes.

## How to Use

I maintain my learning notes locally in `C:\Users\shank\Desktop\ai\LEARNING.md`.
After completing lessons, I manually copy the day's summary into the appropriate daily-log file or use an external automation script (not committed to this repo) to sync.

## Purpose

To have a transparent, chronological record of my AI/ML learning path, including topics covered, struggles, and progress over time.

## Notes

- The `LEARNING.md` file is kept locally and is not part of this repository.
- Automation scripts for syncing are kept separate and not committed here.
